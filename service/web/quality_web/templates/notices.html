Source code

nixpkgs at github.com/NixOS/nixpkgs holds, at the revisions above, the build recipe and the patches of every package and pins its upstream source by hash. nix build github:NixOS/nixpkgs/<revision>#<attribute>.src fetches that upstream source, for example for the GPL licensed bash, coreutils, git, hadolint, shellcheck and squid.

Web image

The web image builds on the official Docker image python:3.14-slim-trixie. Its Debian packages carry their own licences, and their source is in the Debian archive at sources.debian.org. On top of it, the image adds these Python packages from PyPI, pinned in service/web/requirements.txt, and the ALTCHA widget from npm. Each licence is the one the package metadata declares.
