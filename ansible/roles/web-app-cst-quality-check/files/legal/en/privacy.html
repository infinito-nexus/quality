Privacy

What is processed

  • The repository URL, file or text you submit. It is scanned by static tools only and never executed. It is deleted when its job ends and is never served back.
  • The report: rule, path, line, severity and a fixed summary per finding, the commit of a repository and the applied exclusions. It holds no address, user name or email.
  • Your network address, only in process memory and only as a keyed hash that changes every day, to enforce rate limits. A restart of the service drops it.
  • After a login: your user name and whether you belong to the service's group, only in process memory for the session.

How long

Reports are deleted 48 hours after they were written. Job data lives on a memory file system and is gone after the job or a reboot.

What is not processed

The web server of this service writes no access log and no error log for it. Connection setup before the server name is known (TLS handshake errors) can still appear in the host-wide log of the web server. No tracking, no analytics, no cookie for anonymous visitors, and the captcha runs in your browser without contacting a third party.

Outbound requests

To fetch a repository, the service connects to the host you named, through a proxy that refuses private and local addresses. That host sees the service's address and a fixed user agent, not yours.
